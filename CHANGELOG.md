# Changelog

## [0.1.0] - 2026-11-14

- First release as a proper Windows tray widget (Rust + Slint), following the Windows Widget Standard.
- Frameless always-on-top card, tray quit, single instance, portable mode, verified GitHub updates.
- Usage for Claude, Codex, Grok Bot, Cursor (optional), and manual entries via `scripts/fetch.ps1`.
- Derived daily usage from weekly/monthly baselines; warn/bad thresholds in config.
